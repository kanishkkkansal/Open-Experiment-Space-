# 🧪 Open Experiment Space

**A free, open-source virtual lab where you experiment freely. Mix any chemicals, use any apparatus, and see what happens.**

Built by **Team Caffeine Coders** | Track: Education (Smart Education)

---
🔗 **Live Demo:** https://openexperimentspacedesignenhanced-3-2jiphjxx4.vercel.app

## The Problem

Many government schools and under-resourced private schools have no proper science lab. Existing virtual labs like PhET and ChemCollective are mostly fixed, scripted simulations: you can only do what the designers planned.

## Our Solution

Open Experiment Space is an **open-ended** virtual lab. You pick chemicals and apparatus from a sidebar and combine them however you like, in one single workspace. No tabs, no fixed steps. You decide what to do.

## Features

- **One open workspace** for salt analysis, titration and flame test together
- **Choose the form of any compound**: solid (salt) or liquid (dissolved)
- **Control quantity and concentration**: decide how much of each chemical to add, and how much water to dissolve a salt in
- **Live apparatus visuals**: test tubes and beakers change color and texture based on what is inside, with a label showing the current contents
- **Burette / titration nozzle** with adjustable drip speed
- **Pannable and zoomable canvas**, similar to CircuitVerse
- **Detailed compound preview**: the workspace enlarges while selecting a compound to show its color and texture

## Tech Stack

React, Vite, Tailwind CSS

## Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/open-experiment-space.git

# Go into the project folder
cd open-experiment-space

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open the local URL shown in your terminal (usually `http://localhost:5173`).
